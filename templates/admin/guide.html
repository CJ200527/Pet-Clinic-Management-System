What is this system?

This is the Pet Clinic Management System for Paws & Care. It holds the bookings, the patient line, the check-ups, and the payments — all in one place. No paper list and no Excel needed.

Two kinds of people: the client (pet owner) books on the landing page and never logs in. Only Admin and Staff sign in to the dashboard.

Admin — everything Staff — view + daily work Client — no login

The life of one patient

1 Book A guest books on the landing page (pending), or Staff books a walk-in with New Appointment (already approved).
2 Approve Admin accepts (check) or rejects (X) the booking. Same-day bookings join the queue automatically when their time arrives.
3 Queue The patient gets a number when their slot time comes (walk-ins and emergencies can be ticketed immediately).
4 Consult The vet checks the pet: service, diagnosis, treatment, prescription. The fixed service fee becomes the bill.
5 Pay Invoice → mark paid → print the receipt.

The modules, one by one

Dashboard

Admin + Staff · view only
  1. Pick a Period (Today / This Week / This Month / All Time). All the numbers follow it.
  2. Press Refresh (the round arrow) if you just changed something.
  3. The 4 KPI cards: Pending Bookings, Queue Today, Unpaid Bills, Consults Done. Click a card to open its list.
  4. The bell at the top shows how many things need attention.
  5. The charts show Revenue, Top Services, the Bookings trend and the Species mix.

Appointments

Approve / reject: Admin · view: Staff
  1. A guest books on the landing page (/). The booking arrives here as pending.
  2. New Appointment (Staff or Admin) books a walk-in or phone client. Pick an existing client or type a new one, then choose the pet. It saves as approved, ready for the queue.
  3. ✔ = approve (accept). ✕ = reject (decline). Admin only, and it asks for the admin password.
  4. Use search for a name or pet, and the funnel (filter icon) for Period + Status.
  5. Once approved, today's booking joins the Queue by itself when its scheduled time arrives. Afternoon and future bookings wait for their day/time; use Add to Queue only for emergencies or a manual ticket.

Queue

Admin + Staff
  1. Approved same-day bookings appear automatically when their time arrives — no need to add them by hand.
  2. Press Add to Queue only for walk-ins, emergencies, or when a booking must be served early.
  3. Numbers count up each day and never repeat; each appointment can have only one ticket.
  4. The Now-Serving strip shows who is at the counter; the next two are listed below it.
  5. Row icons: play = start serving, check = mark done, skip = patient did not show (kept and marked Skipped), X = delete ticket (Admin only, permanent, asks for the admin password).
  6. Check (done) opens the consultation form already filled in — the appointment, the vet and the service are set, and the fixed fee is shown. Finish the diagnosis and save to complete the visit.
  7. The page refreshes itself every 30 seconds (there is a pause toggle), so due appointments join on their own.

Consultations

Admin + Staff
  1. Log Consultation → pick the appointment and the pet.
  2. Pick the service. Its fixed fee and inclusions appear; the service from the booking is preselected.
  3. Pick the attending vet (only active vets appear in the dropdown).
  4. Write the diagnosis, treatment and notes.
  5. Save. The appointment is completed and an unpaid invoice for the fixed fee is created automatically.
  6. On the detail page: add a prescription in plain text — medicine, dosage, instructions. No stock numbers to maintain.

Clients

Admin + Staff · records only, no login
  1. Search by name or phone number.
  2. Press the view icon to see the profile, the pets and the consultation history.
  3. Edit: name, phone, email, address (Staff allowed).
  4. A new client is created automatically when a guest books — the same phone number means the same client (no duplicates).

Pets

Admin + Staff
  1. Search or filter by species.
  2. View / Edit: name, species, breed, age, weight and notes.
  3. Every pet belongs to one client (the owner).

Vets

Add / toggle: Admin · view: Staff
  1. Add Vet: name, specialty (optional), phone (optional).
  2. Deactivate: the vet disappears from the consultation dropdown (old history stays). Asks for the admin password.
  3. Activate: the vet is selectable again. Asks for the admin password.
  4. For the full profile (photo, license, email, background), use Settings → Vet Profiles.

Settings

Own profile: Admin + Staff · Vet profiles: Admin
  1. My Profile: change your name, email or password. Your username stays fixed.
  2. Photo: choose a PNG, JPG or WEBP image (up to 3 MB) and press Save photo. It appears on the header bar and in the vet directory.
  3. Vet Profiles: press the pencil on a vet to edit their photo, specialty, license, email and background.
  4. Add Vet creates a new vet profile with an optional photo.

Services

Edit: Admin · view: Staff
  1. The clinic has six fixed services: General Checkup, Vaccination, Grooming, Boarding, Surgery Consult and Emergency.
  2. Each one has a fixed fee, a duration and a list of inclusions (what the client gets).
  3. Press the pencil on a service to change its fee, duration or inclusions. It asks for the admin password because fees affect billing.
  4. A changed fee applies to future consultations only — old bills keep the amount they were issued with.
  5. Uncheck Bookable to hide a service from booking; old records keep their history.
  6. Services cannot be added or deleted — the list is fixed.

Invoices

Issue / mark paid: Admin · view: Staff
  1. Issue Bill (Admin) or let the consultation create it automatically.
  2. Pick the client. The reference (appointment or consultation) must belong to that client.
  3. Mark it paid (asks for the admin password) → the receipt appears with a PAID stamp. Cancelling a bill asks too.
  4. Press the print icon for the receipt.

Users

Admin only
  1. Create User: username, full name, role (admin/staff), password (8+ characters).
  2. A new user is pending. Approve it (asks for the admin password) before they can log in.
  3. Reject or delete an account you no longer need. Both ask for the admin password.
  4. You cannot delete yourself or the last admin.

When the clinic asks for your password

What it looks like: press a protected action, and the confirmation card gains a Your admin password box. Type the password of the account you are signed in as, then press Confirm. The eye button shows what you typed.

Why: being signed in is not enough for actions that touch money, access, or other people's records. Retyping the password proves it is really you, so a left-open screen or a mis-click cannot approve or delete anything.

Actions that ask: approve or reject a booking; mark an invoice paid or cancel it; approve or reject a login account; delete a login account; activate or deactivate a vet; delete a queue ticket; change a service fee or inclusion.

If it says "Wrong admin password": nothing changed. Close the message and try again with the correct password. Staff cannot do these actions at all, even if they know a password.

Words you will see

Pending — still waiting for approval.
Approved — accepted, ready for the queue.
Completed — the service is finished.
Cancelled / Rejected — dropped or not pushed through.
Queue number — the patient's turn number for today.
Consult — the vet's check-up record.
Prescription — the medicine and instructions written by the vet.
Invoice — a bill that still has to be paid.
Fixed fee — the set price of a service, the same for every client.
Inclusions — what the client gets for the service fee.
Receipt — proof of payment (PAID).
Period — the date range the numbers cover.
KPI — the big numbers at the top of a page.
CSRF — a hidden security token in forms; automatic, do not touch it.

How to start (for the demo)

  1. Open XAMPP → Start MySQL.
  2. In the terminal: $env:PORT=5001 then python app.py.
  3. Open the browser at http://127.0.0.1:5001/.
  4. Press Login on the landing page → the curtain slides down → Admin / 123 (everything) or Staff / 123 (view + daily work).
  5. If the demo data gets messy: python database/demo_seed.py (about 2 minutes, Admin/Staff accounts are untouched).

Common mistakes to avoid

Phone number: on the booking form it must be 09XXXXXXXXX — 11 digits. Otherwise the server rejects it.

Password: a new account needs 8+ characters. The seeded demo password (123) is for the demo only.

No 'vet' login: a vet is a record (a directory entry), not an account. Do not create a user with the role vet.

Staff limits: Staff can book walk-ins, run the queue, and log consultations, but cannot approve bookings, delete records, edit vet profiles or issue invoices. Ask the Admin for those — and these actions ask the Admin to retype their password.

Period filter: it affects every list page. If rows seem missing, they may be in another period.

Port: 5001 is the standard. Port 5000 belongs to another project (IM 103).
